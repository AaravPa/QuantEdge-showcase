# QuantEdge

QuantEdge is a quantitative-trading product project focused on turning research workflows into a usable investor-facing experience.

## Public showcase boundary

This repository is a portfolio overview, not a redistribution of the private implementation. The original `AaravPa/QuantEdge` repository is a private fork with no repository license, so its source and any employer- or team-specific material are intentionally excluded from this public showcase.

## Verified project scope

The private project work includes:

- A customer-facing MVP and investor dashboard.
- An authenticated ASP.NET Core REST API and admin workflow.
- Chart.js analytics for a stated set of 1,073 NQ trades.
- Quantitative research and backtesting work documented separately from this public overview.

The public repository makes no claim that it contains live market-data integrations, order execution, investor records, or a production trading strategy.

## Engineering focus

- ASP.NET Core and C# web application development
- Authentication and role-aware product surfaces
- Analytics interfaces for research and performance review
- Reproducible quantitative analysis with explicit risk and validation boundaries
